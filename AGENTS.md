# Instructions for AI coding agents

## About this project
A tool that helps students keep track of assignments, starting with adding assignments and seeing how many days remain until each is due.
It's built by a student who is new to coding, so explain everything in plain English.

## Rules
- Build a static website using only HTML, CSS, and JavaScript. No frameworks, build tools, or installs.
- Keep it simple: index.html, plus style.css and script.js if needed.
- It must work when index.html is opened directly in a browser and when it's published on GitHub Pages.
- Never add logins, servers, databases, paid services, API keys, passwords, or real personal data.
- If the project needs to remember things, save them only in the browser (localStorage).
- After every change, summarize what you changed in two to four plain-English bullet points, and tell me exactly how to test it.
- Keep README.md up to date: what the project does, how to use it, and a list of changes.
- If my request is unclear or too big, ask me one question or suggest a smaller first step instead of guessing.
